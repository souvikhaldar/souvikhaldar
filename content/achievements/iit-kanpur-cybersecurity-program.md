![Cybersecurity program milestone at IIT Kanpur](/images/linkedin/iit-kanpur-cybersecurity-program.jpg)

This marked a six-month cybersecurity learning milestone, built around weekday work and weekend study.

The program deepened my interest in security through guidance from Prof. Sandeep Shukla, Rohit Negi, and Anand Handa. The strongest takeaway was that security is not a single subject; it sits across systems, networking, databases, programming, observation, social engineering, and adversarial thinking.

The project work reinforced a practical lesson: to exploit a system, you need to understand how systems are built. That mindset later shaped my approach to secure programming, offensive security tooling, and building defensive products.

I wrote more about this learning phase in [Learning Cyber Security at IIT Kanpur](/articles/cscd/).
